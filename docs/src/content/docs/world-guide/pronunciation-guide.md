## 附錄 A：發音指南

發音表列出本書重要人物、地點和其他用語的讀法。

和寰宇（cosmere）其他世界一樣，司卡德利亞（Scadrial）的讀音也因地區和方言而異。如果這裡的讀法和你或你的玩家不同，你們也可能讀得對！更有可能的是，你們只是和撰寫這份指南的躍界者（worldhopper）來自不同地方。

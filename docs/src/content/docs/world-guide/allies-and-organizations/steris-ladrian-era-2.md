史特芮絲是哈姆司家族（House Harms）唯一的繼承人。她從小就背負著沉重的期望，家族指望她透過婚姻擴大影響力。她把一位得體的名門淑女該學的功課都學得很好，卻發現自己理解世界、應對世事的方式和多數人不同。她特別留意細節，總在社交場合感到焦慮，又習慣事事準備得過於周全，因此和同輩漸漸疏遠。

她遇見瓦希黎恩（Waxillium）後，一切有了改變（見下一節「瓦希黎恩．拉德利安」）。兩人原本只是談妥了一樁契約婚姻，這場婚約卻成了史特芮絲人生中驚險、難以預料又令人振奮的轉捩點。這段婚姻始於義務，最後卻是愛讓她成為拉德利安夫人（Lady Ladrian）。上流社會覺得她和瓦（Wax）是對古怪的夫妻，但有些閱歷豐富的政界人士看得出來，拉德利安家族（House Ladrian）之所以能在財務和政治上東山再起，背後是史特芮絲一手推動。她也為北司卡德利亞（Northern Scadrial）與南司卡德利亞（Southern Scadrial）的外交和貿易打下基礎。這或許為依藍戴盆地（Elendel Basin）爭取到一段關鍵的緩衝期，讓緊張情勢暫時緩和，各方仍能保持對話。

### 短期目標與獎勵

如果你在戰役中採用史特芮絲，個別 PC 為她完成短期目標（goals）後，就有機會獲得她的贊助，並取得贊助者的好處（patron benefit）。

#### 贊助者目標

史特芮絲可能會提出以下短期目標。

**查證消息。** 替史特芮絲查證一則經濟或政治傳聞。你可以參加上流社會的聚會，跟人閒聊打聽，也可以請一家礦業公司的工班喝一輪酒。

**查訪家族產業。** 走訪拉德利安家族的各處資產和商號，查出家族帳簿上的異常從何而來。

#### 贊助者的好處：史特芮絲．拉德利安

史特芮絲能在北司卡德利亞各地提供贊助者待遇（patron amenities）。她可以在拉德利安家族的產業內接待你，也可以替你在別處安排住宿。她講求把錢用在刀口上，因此通常安排簡樸（Modest）或舒適（Comfortable）的住宿。此外，史特芮絲擅長後勤，懂得如何把風險降到最低，也很會事先擬定應變方案。只要你的任務不違背她的利益，她就能提供應變準備（contingency plans），份數上限等於你的階層（tier）。當你擲劇情骰（plot die）時，可以花費一份應變準備，依「史特芮絲的應變準備」表選擇不同的結果。

##### 史特芮絲的應變準備

| 原擲骰結果 | 更改後的結果 |
| --- | --- |
| 空白 | [機遇] 或 [變故] 2 |
| [機遇] | [變故] 4 |
| [變故] | [機遇] |

應變準備要多久才會送到，由 GM 決定。你能依自己的階層，參照「史特芮絲提供應變準備的頻率」表查看多久能向她求助一次。

##### 史特芮絲提供應變準備的頻率

| 階層 | 頻率 |
| --- | --- |
| 1–2 | 每月一次 |
| 3+ | 每週一次 |

政客和有意成神的人若低估史特芮絲．拉德利安，就得自負風險。

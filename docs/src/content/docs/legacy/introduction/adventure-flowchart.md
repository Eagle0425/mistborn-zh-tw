### 冒險流程圖

| 第 1 章：逝者的回聲<br />1024 FE 年｜第一時代角色｜第 1 級<br />PC 在營救遭綁架的團隊首領 Enge 時，發現 Gilded Few 藏在鎢都的基地。他們在血腥政變留下的殘跡中，找到一件以暴行造就的強大神器，也就是永恆尖刺。 |  |
| --- | --- |
|  |  |
| 第 2 章：鍍金面具之後<br />1024 FE 年｜第一時代角色｜第 2 級<br />PC 在 Fellise 參加祕密舞會。跳舞與談情過後，當晚的陰謀演變成致命危機。PC 得在逃離 Gilded Few 的新領袖 Delina Tekiel 前，從舞會主人口中了解永恆尖刺。陸沙德圍城就此開始。 |  |
|  |  |
| 第 3 章：多數與少數<br />1024 FE 年｜第一時代角色｜第 3–4 級<br />隊伍計畫將尖刺藏在隱密的隧道網中。為了找到隧道，他們造訪 Kandor 營造公司，最終揭穿一名 Gilded Few 煽動者的背叛、解決勞資糾紛，並結交新盟友。 |  |
|  |  |
| 第 4 章：永恆寶庫<br />1024 FE 年｜第一時代角色｜第 5–6 級<br />PC 召集盟友、竊取物資，為尖刺建造一座堅固的寶庫。Delina 伏擊隊伍，雙方展開最後一戰，Enge 的真實身分也隨之揭曉。他其實是坎得拉 NeBaal。陸沙德之戰迎來黎明時，NeBaal 請 PC 完成最後一項致命任務，讓後世仍能找到寶庫。 |  |

| 第 5 章：引擎與諜報<br />345 PC 年｜第二時代角色｜第 3 級<br />三百年後，第二時代隊伍為了在國家檔案館行竊而參加一場汽車競賽，並與鍍金三人組發生衝突。PC 偷走一只箱子，裡面裝有創始者之鑰及鍍金地圖的第一塊碎片。 |  |
| --- | --- |
|  |  |
| 第 6 章：飢渴靈魂的渴望<br />345 PC 年｜第二時代角色｜第 4 級<br />三人組炸毀隊伍的藏身處。PC 到依藍戴大學調查鑰匙，潛入菁英兄弟會的入會儀式「午夜試煉」，揭開當代 Gilded Few 的祕密。真相曝光後，PC 與 Kwylliam 決鬥並救出 NeBaal。 |  |
|  |  |
| 第 7 章：敲擊鐵砧<br />345 PC 年｜第二時代角色｜第 5 級<br />隊伍前往蠻橫區尋找第二塊鍍金地圖碎片，遇見一名守護者組織的成員。這個組織因第一時代隊伍的行動而成立，致力於保護尖刺。隊伍與一名法外之徒談判，並與 Bayron 正面交鋒。 |  |
|  |  |
| 第 8 章：致命時尚<br />345 PC 年｜第二時代角色｜第 6–7 級<br />回到陸沙德後（原流程圖如此記載，第 8 章正文則為依藍戴），最後一塊鍍金地圖碎片將在埃拉瑞爾春季沙龍拍賣。PC 假扮模特兒混入會場，Lysarra 卻發動了致命陷阱。PC 取得地圖碎片，但三人組綁走 Wilko 教授，搶先一步奔向尖刺。 |  |
|  |  |
| 第 9 章：一切終於陸沙德<br />345 PC 年｜第二時代角色｜第 8–9 級<br />隊伍與三人組競速前往舊陸沙德，穿越第一時代 PC 設計的寶庫地城，趕去中斷三人組的昇華儀式。PC 必須在往昔的廢墟中擊敗血金術怪物，守護司卡德利亞的未來。 |  |

### 如何使用這套工具

《迷霧之子® 傳承》是寰宇® 角色扮演遊戲在迷霧之子設定中推出的第一部

戰役長度冒險。它有一段以司卡德利亞為舞臺的原創故事，

橫跨兩個時代。第一時代（第 1–6 級）的角色將周旋於舞會陰謀、駭人祕密及陸沙德圍城戰之中。數百年後，他們的選擇仍影響著第二時代。一支新隊伍（第 3–9 級）必須完成一場驚險的尋寶之旅，挫敗心懷不軌的貴族。

### 內容一覽

為了讓遊戲更容易上手，寰宇 RPG 團隊編製了這套主持人工具，為《迷霧之子傳承》的每一章提供下列資料：

- 單頁章節摘要

- NPC 扮演指引

- 戰鬥摘要

- 敵手資料

### 單頁摘要

單頁摘要提供遊戲中可查閱的筆記和提醒，標出每場戰鬥、對話、事件與試煉，以及所有時代跳躍側欄和傳承時刻。對話會列出相關的 C、S 與 F，分別代表認知防禦、靈性防禦與專注點。試煉條件以「(x/y)」表示，意即在累積 y 次失敗前取得 x 次成功。摘要也附有可在螢幕上操作的進度記錄器，供你記錄試煉的成功與失敗、對話的專注點（如適用），以及事件的機遇或變故。

### 其他工具

除了這套主持人工具，也有下列選用配件，可豐富玩家的遊戲體驗：

- 《迷霧之子傳承》時代跳躍工作表（記錄第一時代的事件，以及這些事件在第二時代造成的連鎖影響）

- 《迷霧之子傳承》玩家講義（附錄 D 的可列印講義，以及附錄 E 的休整地圖）

- 《迷霧之子傳承》主持人地圖與美術（可列印的地點地圖與美術）

- 《迷霧之子傳承》戰鬥地圖與指示物（可列印的

一吋方格戰鬥地圖，以及 PC 在戰鬥中會遭遇的所有敵手指示物）

可另行購買的產品包括收錄本冒險物品的《迷霧之子物品卡》，以及適用於司卡德利亞各種冒險的《迷霧之子主持人屏風》與《迷霧之子劇情牌組》。此外，《迷霧之子玩家速查表》和《迷霧之子主持人規則概要》可供教學和解說遊戲，兩者都能在 CosmereRPG.com 的資源頁免費取得。

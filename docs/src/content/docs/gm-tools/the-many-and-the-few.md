扮演 Cynwise

特質：嘴上不饒人、善於觀察、勇敢。目標：逃出鎢都，回到陸沙德。外貌：Cynwise（「SIN-wise」，they/them）是司卡青少年，

棕褐色皮膚沾著灰，瀏海長短不齊，身穿藏著許多暗袋的破舊外套。眼神敏銳，彷彿隨時在盤算。

Cynwise 出生在陸沙德的巷弄。身為街童網絡的一員，靠替肯付錢的人打零工勉強過活。Cynwise 常用帶刺的評論和探問試探陌生人，平時話很少，有利可圖時才會開口，一說就說得很快。Cynwise 向來不輕易信人，遭到綁架又目睹 Vadilek 的殺人儀式後，更加戒備。被關起來從來不在計畫之內，但 Cynwise 總能找到出路。

扮演 Kandor

特質：不屑一顧、精明、頑強。目標：維護自己在陸沙德新興

商人階層中的利益。外貌：Kandor（「CAN-door」，he/him）是四十多歲的司卡男子，

膚色黃褐，面容飽經風霜，看上去至少六十歲。他衣著招搖，看起來比實際上富有得多。

Kandor 曾是為鋼鐵教廷做事的司卡工匠，幾十年來一直從事艱苦的建築工作。多年的苦役讓他留下跛腳的毛病，走路得拄拐杖。維護陸沙德地下的祕密隧道本該是他最後一項工程，但最後帝國意外覆滅，讓他活了下來。Kandor 靠苦役中習得的技藝創辦自己的營造公司。他試圖遠離受奴役的過往，專注於自己在陸沙德新興商人階層的前途。近來圍城使他財務吃緊，一連串工安事故又讓工人罷工，生意陷入停頓。

扮演 Bezryl

特質：莊重、富同情心、憂心。目標：找到兄弟 Fadwal，協助調停

Kandor 營造公司的爭議。外貌：Bezryl（「BEZ-rill」，she/her）是三十出頭的

泰瑞司女性。身為守護者，她栗褐色的頸部和手腕戴著飾品，大多是紅銅製的。

Bezryl 是守護者，也是一名藏金術師。她的金屬意識庫儲存各種知識。她專研建築及工程，收藏歷史上的施工技術與罕見的建築圖紙。Bezryl 來陸沙德是為了尋找兄弟 Fadwal，自從兩人年輕時他被帶走當侍從官，就再也沒見過他。為了籌措尋人的費用，Bezryl 主動擔任 Kandor 的建築顧問，如今又臨時當起調停人。她總是搶先伸出援手、立刻行動，覺得自己理應解決世間種種難題。

扮演 Duvall Haught

特質：居高臨下、精於算計、毫無道德顧忌。目標：證明貴族優越，討 Delina Tekiel 歡心。外貌：Duvall Haught（「due-VALL HOTT」，he/him）是

年輕貴族，雙眼漆黑醒目、膚色米白，金髮整齊往後梳。

和 Vadilek 多數學生一樣，Duvall 相信貴族天生比司卡優越。他雖然敬佩 Vadilek 的力量與野心，卻很快改向 Delina 效忠，並設法博取她的敬重。Duvall 是錢幣射手，也曾在 Vadilek 和 Murn 指導下精研血金術，協助製作植入永恆尖刺所需的尖刺網。最近，Duvall 替自己植入尖刺，取得煽動情緒的能力，並用它在司卡之間煽起動亂。

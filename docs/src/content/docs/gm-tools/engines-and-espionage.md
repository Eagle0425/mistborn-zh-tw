扮演 Eliane Vorn 隊長

特質：強悍、威嚴、沉著堅定。目標：保護 Lysarra 及國家檔案館。外貌：Eliane Vorn（「eh-lee-AH-nah VOHRN」，she/her）

Vorn 出身 Morgenthax 犯罪家族，曾任依藍戴警員，失去徽章後才接受國家檔案館的警備隊長職位。Lysarra 說服 Kwylliam 雇用 Vorn，此後 Vorn 一直與鍍金三人組共事。她負責替自己的戀人 Lysarra 與依藍戴地下犯罪勢力牽線。

扮演 Azmine Wilko 教授

特質：待人有禮、重視歷史、勤勉。目標：運用對過去的認識改善未來。外貌：Azmine Wilko（「AZ-meen WILL-koh」，

she/her）是克羅司混血女性，膚色藍灰，下顎線條柔和，一頭波浪長髮用髮夾固定。她穿著粗花呢西裝，提著改裝過的皮製公事包，一看就像位教授。

Wilko 教授相信「人必須從歷史中學習」。她認真實踐這句話，以歷史實例形塑自己的看法，也常引用過往名人的話。Wilko 請 PC 允許她記錄他們的經歷，好留給未來的歷史學家。她開玩笑將那本按顏色分類的巨型日誌稱為「紅銅意識」。身為校園裡唯一的克羅司混血教授，她習慣被人當成異類。她把教授的服裝和頭銜當作護甲，盡量避免衝突。Wilko 雖然是祕密結社守護者組織的成員，卻很不擅長說謊。

扮演 Kwylliam Elariel

特質：愛挑釁、漫不經心、放蕩。目標：成為眾人注目的焦點，讓事情保持有趣。外貌：Kwylliam Elariel（「KWIL-ee-um eh-LAIR-ee-al」，

he/him）是二十五歲上下、身材瘦高的貴族，顴骨分明，膚色金棕，深褐色頭髮亂翹。他穿著浮誇，臉上總掛著玩味的表情。

Kwylliam 向來不必為自己的行為負責，想說什麼、想做什麼都隨他高興。他愛挑釁別人，有時連盟友也不放過。他的態度總在冷嘲熱諷與漫不經心之間打轉。他喜歡個性誇張又熱烈的人，最痛恨無聊。他相信只要有人關注自己，就是好事。

扮演 Lysarra Tekiel

her）是二十五歲上下、輪廓分明的女性，眼神銳利，深色捲髮優雅地梳向一側，五官如瓷器般精緻而銳利。她的穿著低調，剪裁極為講究。

Lysarra 通常是房裡最聰明的人。她辦成許多事，靠的是讓別人以為她的主意是他們自己想出來的。她表面慷慨、迷人又有耐心，私下卻愈來愈厭倦安撫那些錢多又不動腦的男人。她很喜歡自己的伴侶 Eliane Vorn 隊長，但歸根究柢，Lysarra 只效忠自己。為了成功，她什麼都肯做。

當敵人在速度圈內被減速時，Vorn 每個輪次也都選擇慢速輪次，通常依序執行以下行動。

- 移除自己身上的 1 延遲點（[1行動]）。「汲取

速度」已抵銷另一點，因此她身上已無延遲點。

- 使用「扭曲時間」（[1行動]）傷害速度圈內優先處理的目標。她的增益［速度 +2］加值適用於所有攻擊檢定和傷害。

- 朝該目標移動（[自由行動]），再用

左輪手槍握柄打擊（[1行動]），使目標倒地。

- 維持「燃燒鎘」（[自由行動]）。

如果盟友身陷險境，Vorn 會立刻改以保護他們為優先，使用「戰術撤離」指揮他們離開危險區域。請留意，她在速度圈內時，無法影響圈外的盟友。

煽動者的戰術

煽動者會對敵人所在或可能經過的地形使用化為灰燼，接著燃燒鋅，煽動附近目標的恐懼或怒氣，並每回合維持效果。煽動者避免直接交戰，只有當敵人已受到其他人威脅時才用佩劍打擊。如果成為直接攻擊的目標，煽動者會脫離並換位，盡可能待在戰鬥外圍攪亂局勢。

你的角色擅長什麼？是魅力十足、反應機敏，還是安靜內斂？是身手敏捷、動作靈巧，還是總是笨手笨腳？是意志堅定如鐵，還是為了避免衝突而輕易妥協？是滿腹智慧，還是像報紙連載故事的主角那樣輕浮？

這些特質，以及角色的許多其他特質，都由你記錄在角色紙上的數據呈現。透過這些數據，你的角色才能與遊戲規則互動，進而與司卡德利亞（Scadrial）的世界互動。

### 認識你的數據

本章詳述你在角色建立（Character Creation）時選定的數據（見第 1 章），以及這些數據如何影響遊戲的各個面向。你的數據包括以下項目：

**屬性（Attributes）。** 六項屬性決定你的天生特質。遊戲進行時，你不必時時關注這些基礎數據，但它們會影響許多其他數據。

**防禦（Defenses）。** 其他角色對你進行檢定（Test）時，你的防禦決定對方的檢定是否成功。同樣地，你的能力也會以敵人的防禦為目標。敵人的防禦越高，檢定就越困難。

**偏轉值（Deflect）。** 偏轉值代表你抵禦傷害的能力，能讓你減少受到的能量（Energy）、衝擊（Impact）與銳利傷害（Keen Damage）。

**專長（Expertises）。** 技能（Skills）反映你能做什麼，專長則反映你懂些什麼。這些專門知識能幫助你應對不同文化、回想資訊、製作火器，以及處理許多其他事情。

**生命值（Health）、專注點（Focus）與授予（Investiture）。** 生命值保護你免於受傷或死亡，專注點與授予則用來驅動你的天賦（Talents）及其他能力。

**技能。** 技能代表你透過學習與練習獲得的能力，決定你的檢定有多大機會成功。

**其他數據。** 屬性也會影響角色的其他面向，例如速度（Speed）會影響移動速率（Movement Rate）。各屬性的小節會說明它影響哪些數據，而角色建立流程會引導你計算這些數據。

### 實體、意識與靈魂

在整個寰宇（Cosmere）中，現實由三個面向構成：實體界（Physical Realm）、意識界（Cognitive Realm）與靈魂界（Spiritual Realm）。你的許多數據也分屬這三個面向，如同角色紙上的三欄所示：

**實體（Physical）。** 實體數據包括力量（Strength）與速度這兩項屬性、所有使用這兩項屬性的技能，以及實體防禦（Physical Defense）、生命值、移動速率和舉重能力（Lifting Capacity）。它們列在角色紙的第一欄。

**意識（Cognitive）。** 意識數據包括智力（Intellect）與意志（Willpower）這兩項屬性、所有使用這兩項屬性的技能，以及意識防禦（Cognitive Defense）、專注點和恢復骰（Recovery Die）。它們列在角色紙的第二欄。

**靈魂（Spiritual）。** 靈魂數據包括察覺（Awareness）與風采（Presence）這兩項屬性、所有使用這兩項屬性的技能，以及靈魂防禦（Spiritual Defense）、授予和感知範圍（Senses Range）。它們列在角色紙的第三欄。

這樣分類除了能讓角色紙井然有序，也會用在少數遊戲規則中。例如，學者（Scholar）英雄路徑（Heroic Path）的第一項天賦，會讓你獲得額外的意識技能等級（Ranks）。受力量或速度影響的技能屬於實體技能；受智力或意志影響的技能屬於意識技能；受察覺或風采影響的技能則屬於靈魂技能。

每個角色都有六項屬性（attribute），決定與生俱來的特質：力量（Strength）、速度（Speed）、智力（Intellect）、意志（Willpower）、察覺（Awareness）與風采（Presence）。

每項屬性都以數字表示，數值越高越好。這些數值決定角色在身體、心智與靈魂方面的極限。在司卡德利亞（Scadrial），大多數人類、坎得拉（kandra）與克羅司混血（koloss-blooded）的屬性都不超過 2。不過，玩家角色（Player Character）即使只有第 1 級也非比尋常；隨著等級提升，你可以將屬性值提高到 5。克羅司混血角色、受授予的（Invested）角色、巨獸與其他強大生物，甚至可以超過這個範圍。

每項技能（skill）都對應一項屬性，角色紙上會以括號標示。後面的〈技能〉一節會說明，該屬性值如何影響技能修正值（Skill Modifier），進而影響你使用該技能時成功的機會。

屬性也決定角色的其他要素，從能負荷的重量，到擁有多少項專長（Expertise）都有影響。以下各節會詳細介紹這些屬性，以及它們如何影響遊戲。

### 力量

力量代表你的體力、強韌程度與運動能力，包括你能發揮的原始力量與力道，以及體質與耐力。

#### 舉重與負重

力量決定你能舉起和攜帶多少重量，詳見〈舉重與負重能力〉表。

##### 舉重與負重能力

| 力量 | 舉重能力（Lifting Capacity） | 負重能力（Carrying Capacity） |
| --- | --- | --- |
| 0 | 100 磅 | 50 磅 |
| 1–2 | 200 磅 | 100 磅 |
| 3–4 | 500 磅 | 250 磅 |
| 5–6 | 1,000 磅 | 500 磅 |
| 7–8 | 5,000 磅 | 2,500 磅 |
| 9+ | 10,000 磅 | 5,000 磅 |

#### 舉重能力

舉重能力代表你獨自嘗試一次時，最多能舉起的重量。你無法長時間支撐這麼重的東西，但有需要時，可以安全地將它舉過頭頂。

#### 舉起與移動角色

經 GM 判定，你或許能舉起並移動被你擒抱（Grapple），或以類似方式陷入束縛（Restrained）的不情願角色。不過，視該角色、附近盟友與環境而定，你可能會受到傷害、必須通過檢定（Test）才能移動對方，或承受其他效果。

力量強大的角色擅長使用重型武器（Heavy Weaponry）。

#### 負重能力

雖然本書許多物品都標明重量，但你不必隨時精算自己攜帶了多少東西。合理就好——如果你想帶著整座圖書館的書去冒險，GM 多半會問你，要怎麼運送這麼豐富的知識！需要追蹤攜帶重量時，可以參考以下準則。

負重能力代表你步行時能輕鬆攜帶的重量。雖然你可以暫時超過這個重量，最多達到舉重能力，但這會拖慢你的速度，最後讓你筋疲力盡。

如果你在超過負重能力的情況下移動，將陷入減速（Slowed）。計算重量時，須包含身上穿戴與攜帶的所有東西。

此外，每當超過負重能力的時間累計達 60 分鐘，你就會陷入精疲力竭（Exhausted）[−1]。長休息（Long Rest）後，累計時間歸零。

#### 受影響的數據

力量值會影響你的多項數據。力量改變時，請更新角色紙上的以下項目：

- 實體防禦（Physical Defense）

- 生命值（Health）

- 舉重能力

- 徒手攻擊（Unarmed Attack）傷害骰

- 以力量為基礎的技能修正值：運動（Athletics）、重型武器

### 速度

速度代表你的迅捷與靈巧，包括動作的細膩程度與整體反應速度。

#### 移動速率

速度決定你在戰鬥與其他緊張情境下，能移動多快。使用第 10 章介紹的移動（Move）行動時，你最多可以移動等同移動速率（Movement Rate）的距離，詳見〈移動速率〉表。其他能力允許你移動時，會說明可以使用哪一種速率。

一般而言，你以步行或類似方式沿著地面移動。其他移動類型的說明，請見第 10 章〈移動與站位（Movement and Positioning）〉一節。

#### 移動速率

| 速度 | 移動距離 |
| --- | --- |
| 0 | 每行動 20 呎 |
| 1–2 | 每行動 25 呎 |
| 3–4 | 每行動 30 呎 |
| 5–6 | 每行動 40 呎 |
| 7–8 | 每行動 60 呎 |
| 9+ | 每行動 80 呎 |

#### 戰鬥外的移動

如果需要判定非戰鬥情況下的移動速率，你大約每 10 秒能完成三個行動。同樣地，要計算 10 秒內能跑多遠，將移動速率乘以 3 即可。

#### 受影響的數據

速度值會影響你的多項數據。速度改變時，請更新角色紙上的以下項目：

- 實體防禦

- 移動速率

- 以速度為基礎的技能修正值：敏捷（Agility）、輕型武器（Light Weaponry）、隱匿（Stealth）、竊術（Thievery）

### 智力

智力代表你運用智能與才智的能力，包括儲存與回想知識，以及推論事實的能力。

#### 額外專長

建立角色時，所有角色都可以選擇兩項文化專長（cultural expertise）。如果智力值為 1 或以上，你可以額外選擇等同智力值數量的專長（詳見本章後面的〈專長〉一節）。

如果你的智力隨等級提升而增加，每增加 1 點智力，就能選擇一項新的專長。

#### 受影響的數據

智力值會影響你的多項數據。智力改變時，請更新角色紙上的以下項目：

- 意識防禦（Cognitive Defense）

- 專長數量

- 以智力為基礎的技能修正值：工藝（Crafting）、推理（Deduction）、藏金術（Feruchemy）、學識（Lore）、醫學（Medicine）

### 意志

意志代表你的決心與心智韌性，包括意識的抗壓能力、貫徹意願以影響他人的能力，以及抵抗外在影響的能力。

#### 恢復骰

恢復骰（Recovery Die）決定你喘口氣時，恢復生命值與專注點（Focus）的效率（見第 9 章〈休息（Resting）〉）。意志決定恢復骰的大小，詳見〈恢復骰〉表。

#### 恢復骰

| 意志 | 恢復骰 |
| --- | --- |
| 0 | 1d4 |
| 1–2 | 1d6 |
| 3–4 | 1d8 |
| 5–6 | 1d10 |
| 7–8 | 1d12 |
| 9+ | 1d20 |

#### 受影響的數據

意志值會影響你的多項數據。意志改變時，請更新角色紙上的以下項目：

- 意識防禦

- 專注點

- 恢復骰

- 以意志為基礎的技能修正值：鎔金術（Allomancy）、紀律（Discipline）、威嚇（Intimidation）

### 察覺

察覺代表你的智慧，以及你與周遭世界的連結，包括感知環境，以及與身邊其他人建立連結的能力。

#### 感知

感知（Senses）不僅包含視覺與聽覺，也包含你感受世界的其他方式。察覺越高，當黑暗、噪音或其他干擾遮蔽感知時，你能感知的距離就越遠。使用〈感知範圍〉表決定你的感知範圍（Senses Range），再參閱本章後面的〈感知〉一節，了解如何使用這個範圍。

#### 感知範圍

| 察覺 | 感知範圍 |
| --- | --- |
| 0 | 5 呎 |
| 1–2 | 10 呎 |
| 3–4 | 20 呎 |
| 5–6 | 50 呎 |
| 7–8 | 100 呎 |
| 9+ | 不受感知遭遮蔽影響 |

#### 受影響的數據

察覺值會影響你的多項數據。察覺改變時，請更新角色紙上的以下項目：

- 靈魂防禦（Spiritual Defense）

- 授予（Investiture），除非你使用風采計算

- 感知範圍

- 以察覺為基礎的技能修正值：洞察（Insight）、感知（Perception）、求生（Survival）

### 風采

風采代表你的魅力與氣度，包括影響他人、建立融洽關係，以及接觸廣大群眾的能力。

#### 建立人脈

冒險來到城市與其他有人居住的地方時，你常會想知道角色在當地是否有熟人。GM 可以參考你的風采值，判定你過去是否曾在該地區停留夠久，足以建立可供求助的人脈（Connections）。〈建立人脈（Establishing Connections）〉表提供建立這些人脈所需時間的參考，但實際情況會有所不同，由 GM 判定。

#### 建立人脈

| 風采 | 建立人脈所需時間 |
| --- | --- |
| 0 | 1 年 |
| 1–2 | 50 天 |
| 3–4 | 5 天 |
| 5–6 | 1 天 |
| 7–8 | 1 小時 |
| 9+ | 你早已聲名遠播。即使從未造訪的地方，<br />也有你的人脈。 |

#### 受影響的數據

風采值會影響你的多項數據。風采改變時，請更新角色紙上的以下項目：

- 靈魂防禦

- 授予，除非你使用察覺計算

- 已建立的人脈

- 以風采為基礎的技能修正值：欺騙（Deception）、領導（Leadership）、說服（Persuasion）

## 防禦

各項屬性組合成你的防禦（Defense），保護你免受不利效果影響。你有三項防禦值：實體防禦受力量與速度影響，意識防禦受智力與意志影響，靈魂防禦受察覺與風采影響。

### 防禦與難度等級

實體防禦、意識防禦與靈魂防禦值的計算方式如下：

10 + 該類別的兩項屬性之和 + 任何加值或減值

角色對你進行檢定時，通常會以與該技能相同類別的防禦為目標，除非促使這次技能檢定（Skill Test）的效果另有說明。你對應的防禦就是該次檢定的難度等級（Difficulty Class，DC）。

一般而言，實體防禦保護你免受實體檢定影響，意識防禦保護你免受意識檢定影響，靈魂防禦則保護你免受靈魂檢定影響。（各項技能所屬的類別，請見本章開頭的〈實體、意識與靈魂〉一節。）

尤其在對其他角色進行檢定時，要留意防禦可能不是影響 DC 的唯一因素，詳見本章後面的〈技能〉一節。

## 偏轉值

敵人對你的攻擊檢定成功，或你因其他來源受到傷害時，通常會降低生命值，詳見本章後面的說明。不過，護甲（Armor）或其他效果可以提供偏轉值（Deflect），將衝擊（Impact）、銳利（Keen）與能量傷害（Energy Damage）減少等同偏轉值的數值。例如，你的偏轉值為 2，受到 5 點能量傷害時，會偏轉 2 點傷害，然後將生命值減少 3 點。

偏轉值也能讓你在遭受嚴重傷勢時得到一些保護，詳見第 9 章〈傷勢〉。

> 人們一看見依藍德（Elend）就振作起來。他的風采不知怎地帶來了希望，連微風（Breeze）都無法用鎔金術仿效。

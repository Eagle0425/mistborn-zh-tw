無論是潛入貴族的堡壘、在陸沙德（Luthadel）街頭追蹤行蹤不定的目標，或拼湊棘手調查中的各項線索，這些攸關重大的場景都是冒險的重要部分，但進行方式與戰鬥或對話大不相同。本章提供進行這些試煉（Endeavor）的指引，說明如何決定試煉的發展，並讓過程保持緊張有趣。如同本書的其他內容，你可以依自己的喜好，讓試煉有明確架構，或採取彈性的方式，也可以加入新規則或變體，突顯場景的主題。

### 布置場景

試煉的核心，是讓你朝明確的目標努力，並靈活結合角色扮演與技能檢定（Skill Test），決定結果與後果。本章針對四種常見試煉提供具體指引：調查（Discovery）、探索（Exploration）、任務（Mission）與追逐（Pursuit）。但這些只是構想，可能性沒有盡頭。試煉中的時間，會以最適合故事的速度流動。前一刻，GM 可能以鏡頭「拉遠」的方式，將數小時的事件化為一段蒙太奇敘述。下一刻，你們又可能把鏡頭「拉近」，聚焦在棘手的謎題或環境危險，讓全團享受當場逐步演出的樂趣。時間如此靈活，試煉又能涵蓋各式各樣的行動，使它成為所有場景類型中最能彈性調整的一種。當團體開始追求某個目標，你們想在桌邊實際演出過程，卻又不適合用戰鬥或對話場景處理時，GM 通常就應布置一場試煉。

### 確立目標與情勢

試煉開始時，GM 應清楚說明你的目標，或至少是你自認的目標，以及你將面對的情勢，例如環境與阻礙。故事如何將你帶入這個場景，通常就已讓目標相當明確。也許上一場戰鬥的最後一名對手逃走了，你們正穿梭城市街頭追趕；也可能你們已動身前往蠻橫區（The Roughs），尋找某個幫派的藏身處。有時，你不清楚角色為何來到某個地點，GM 就可能需要更明確地說明你的目標。

### 設定試煉門檻

GM 會根據你的目標與試煉情勢，決定是否為這個場景使用團體門檻（Collective Threshold）。如果使用，就會選定試煉結束前需要累積多少次成功或失敗，詳見「團體門檻」與「設定門檻」。GM 通常不會向你透露這些資訊，而是將其留在幕後，作為安排試煉故事發展的依據。

### 介紹特殊規則

最後，GM 會概述這場試煉採用的任何特殊規則。如果場景使用特殊機制，你應了解其基本運作方式，才能順暢地參與並運用它們。

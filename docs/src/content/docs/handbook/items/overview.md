在迷霧與陰謀籠罩的司卡德利亞（Scadrial）世界冒險，可能充滿險阻。你的隊伍（Party）需要備妥行裝，才能生存並有所發展。除了盒金（Boxing），也就是北司卡德利亞的貨幣，備妥武器（Weapon）、護甲（Armor）與裝備（Equipment），也能幫助你行遍這個世界。

若要展開漫長或遙遠的遠征，你可能還會想了解旅費，包括住宿、坐騎與交通工具的費用。如果你的角色（Character）想要自己設計的訂製裝備，甚至可以投入工藝（Crafting）製作。

### 使用物品

使用物品的規則，大多列在各物品的介紹段落。不過，以下先介紹一些適用於多種類型物品的通用規則。

### 專家特性（Expert Trait）

除非另有說明，使用本章的物品不需要任何特殊專長（Expertise）。不過，有些武器與護甲具有專家特性，只有在你具備該武器或護甲的專長時，才能獲得這些特性提供的收益。

### 充能（Charge）

有些物品，例如藏金術師（Feruchemist）的金屬意識庫（Metalmind），具有一點或多點充能，可用來驅動特定效果。對藏金術（Feruchemy）而言，金屬意識庫的充能上限由你的藏金術技能等級（Rank）決定；未綁定金屬意識庫（Unkeyed Metalmind）與藏金術徽章（Feruchemical Medallion）的充能上限，則在製作物品時決定，詳見第8章。充能通常代表金屬意識庫能儲存多少與該藏金能力相關的特質。個別物品可能會進一步說明如何使用其充能，但除非另有說明，以下規則適用於所有這類物品。

### 啟動具有充能的物品

有些具有充能的物品，必須以特殊方式啟動，例如使用互動（Interact）行動。若未特別說明，你可以不花費行動（Action）就花費一點充能。花費充能時，先觸發該物品的效果，接著失去該點充能，直到你以指定的方式為物品補充充能為止。

### 為物品補充充能

具有充能的物品會說明如何補充充能。若未列出方法，該物品的充能便無法恢復。

### 受授予的物品（Invested Item）

有些物品永久灌有授予（Investiture）、與金屬之子（Metalborn）的能力相連，或以其他方式與意識界（Cognitive Realm）或靈魂界（Spiritual Realm）相連。這些物品是受授予的（Invested），可能較難以鎔金術（Allomancy）或其他效果影響；有些情況下，甚至更難偵測。血金術尖刺（Hemalurgic Spike）與灌有任何形式授予的物品，都是受授予的物品；用於藏金術、且具有至少1點充能的金屬意識庫也是如此。若一項效果對受授予的物品有不同作用，該效果的規則會特別說明。

### 具有數據的物品

本手冊通常不會為物品名稱使用特殊格式。不過，若有必要提醒讀者某件物品具有專屬規則或數據，其名稱就會以粗斜體顯示。例如，一份冒險文本（Adventure）可能寫道：「角色找到一個***開鎖器***（Lockpick）。」這便是在提醒你，它並非只是敘事中的物品，應查閱本章，了解它在規則中如何運作。
